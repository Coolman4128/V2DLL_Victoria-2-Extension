# R02n — frozen M3 per-call lifetime and phase contract

R02n examines the existing `StateSavingsNormalize` hook without changing its code, settings or numeric behavior. The current helper does **not** retain a native pointer across calls: it resolves the session's country vector, country, list node and state afresh during each invocation. Its only persistent local state is a diagnostic Boolean. The future automation rule requiring stable IDs and generation checks therefore does not apply to this helper's pointer storage. This source fact does not prove that each resolved object stays valid for the duration of the call.
