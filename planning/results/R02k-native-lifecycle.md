The state had `CState` vptr `0x00C0D78C`; raw `+0x228/+0x22C/+0x230` remained zero and `+0x234` pointed to itself. The state `+0x5C` word was `2`, matching the sampled session-vector slot index, and country `+0x1C` contained raw `0x004B4E50` (three-byte `PNK` tag). A pinned `CState` vtable method reads `+0x5C` and compares it to another index, while separate native code compares country `+0x1C` bytes to `REB`; a pinned constructor independently zeroes the words at source-designated savings offsets and stores the self pointer. This supports the narrow layout and a plausible owner-index relation for this sample, **not** monetary field meaning/units, a globally stable ID, unique owner, country-vector equivalence across routes, allocation lifetime or exclusive savings-write phase. No pre-save `+0x5C`/TAG value was read, so persistence of those values is not claimed. The state nodes were resolved anew after load; no native pointer was carried through it.
