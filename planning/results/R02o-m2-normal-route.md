# R02o — frozen M2 quantizer normal-route input contract

R02o determines the bounded normal inputs to the existing M2 `AfterPopDaily` hook and what its frozen heuristic would do with the clean original-Lua/HPM R02j sample. It does **not** change source, settings, POP quantization, PinFpu or any other multiplayer stabilization behavior. A no-op on an actual market-root path is a valid existing behavior, not a reason to invent a POP mutation. The accepted Win32 DLL, pinned original PE32 EXE and R02j native sample are reused; no new candidate or speed-5 timing run is part of this packet. All current production profiles remain Rejected/WITHHELD; parent S02/R02 and S03 barriers are unchanged.

The pinned native callee's bounded normal path reads market `+0x804/+0x808` as a goods vector and `+0x7E4` as a table base, combining country index and good ID; that is distinct from the fork heuristic's `+0x44/+0x48` probe. A raw `.text` `E8` target scan found one decoded direct call to `0x485E40`, one to its enclosing country loop, and two to the market-daily producer. No exact absolute pointer to those three entries was found in `.rdata` or `.data`. These are bounded direct-call/data-pointer checks, not proof against computed calls, runtime-stored pointers or exceptional routes. The copied native prologue reloads EAX from `fs:[0]` before first use after the fork entry thunk's EAX capture; the normal caller's immediate continuation does not branch on inherited EFLAGS in the inspected span. `pushad/popad` preserves normal GPR results but not EFLAGS/x87/XMM state, and `PinFpu` intentionally changes FP controls. The single R02j return pair supports this ordinary ABI route without certifying exceptional unwind, scratch reentrancy or all-thread lifetime.

The current frozen defaults remain `PATCH_POP_QUANTIZE=1` and `POP_QUANTIZE_KEEP_BITS=12`; 19 signed 64-bit slot offsets and rounding/PinFpu behavior are unchanged. The private `R02o/heuristic-inventory/` lane captures exact source lines and sample-specific predicates; `R02o/native-closure/` pins 11 exact complete PE instruction spans and its bounded caller/ABI interpretation. Root independently verified source/compiled paths and every native span. No fresh original-Lua rerun was justified: static work identified no specific competing POP-bearing input to resolve, and repeating R02j's market sample would not close indirect or exceptional limits. This packet does not claim the fork callback executed or that quantization never runs on all inputs.
